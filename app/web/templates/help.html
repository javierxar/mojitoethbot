{{ icon('bot') }} ¿Qué es este bot? {{ icon('chevron') }}
Un programa que compra y vende Ethereum (ETH) por vos en Bitso usando USDT (dólares digitales). Busca ganar un poco en cada subida y bajada normal del precio.
{{ icon('layers') }} ¿Cómo funciona? {{ icon('chevron') }}
Usa grid trading: arma una "grilla" de precios alrededor del precio actual. Si ETH baja hasta un nivel de compra, compra un poco. Cada compra queda con su propio objetivo de venta un escalón más arriba (~1,25%), suficiente para cubrir las comisiones de Bitso (~0,72% ida y vuelta) y dejar ganancia. La grilla se mantiene fija; solo se rearma si el precio se aleja mucho, y nunca pone a la venta ETH por debajo de lo que costó. Revisa el precio cada 15 minutos.
  • En Resumen → Grilla de precios ves los niveles: en rojo las ventas, en verde las compras y en azul el precio actual.
  • La franja sombreada es la zona de espera: mientras el precio se mueva ahí adentro, el bot no opera.
{{ icon('trending') }} ¿Cómo leer los resultados? {{ icon('chevron') }}
  • Hoy / Desde el inicio — Cuánto cambió el valor total de tu portfolio (USDT + ETH). Incluye la suba o baja del precio de ETH que tenés en cartera, no solo lo que hizo el bot.
  • Ganancia del bot (neta) — Lo que ganó el bot con ventas ya cerradas: USDT recibidos (ya descontada la comisión de venta) menos lo que costó ese ETH (incluida la comisión de compra). Las comisiones son las reales que cobró Bitso; si aparece "≈", Bitso no confirmó el dato y se estimó con 0,36%.
  • Vs. no operar (en Rendimiento) — Diferencia entre tu portfolio actual y lo que tendrías si hubieras dejado todo como estaba al inicio. Positivo = el bot te dejó más plata que no hacer nada.
  • Reiniciar punto de partida (en Rendimiento) — Si depositás o retirás plata en Bitso, usalo para que el depósito no cuente como ganancia (o el retiro como pérdida).

  • Lateral — El precio va y viene (ADX < {{ adx_threshold | int }}). Es el escenario ideal para la grilla.
  • Tendencia — Hay una tendencia fuerte (ADX ≥ {{ adx_threshold | int }}). El bot puede operar rupturas de precio.
{{ icon('toggle') }} Controles {{ icon('chevron') }}
  • Encender / Detener (en Resumen) — Prende o apaga el bot. Apagado no compra ni vende.
  • Chequear ahora — Hace un chequeo en el momento, sin esperar los 15 minutos.
  • Modo de operación — Simulador: practica sin plata real (misma lógica y mismas comisiones). Live: opera de verdad en Bitso. Siempre pide confirmación antes de cambiar.
  • Notificaciones — Mails con cada compra y venta, errores, pausas y un resumen diario. Ahí mismo está la guía para configurar Gmail.
  • Exchange API — Las credenciales de Bitso que usa el bot en modo live.
